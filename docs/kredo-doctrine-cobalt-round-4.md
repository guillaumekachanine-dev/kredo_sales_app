# KREDO — Doctrine Cobalt Round 4

## Nouveaux livrables produits

Trois nouveaux visuels ont été produits dans la direction `Doctrine Cobalt`:

- un `drawer` générique desktop ouvrant à droite
- une vue `mobile cockpit`
- une vue `mobile detail/action`

## Intentions

### Drawer générique

Objectif: poser un patron d’interface transversal, réutilisable dans tous les modules du produit.

Éléments visés:

- header avec titre, contexte et fermeture
- bloc résumé d’entité
- quick facts / KPI
- navigation interne ou sections
- corps scrollable
- module IA de synthèse
- footer d’actions sticky

### Mobile cockpit

Objectif: montrer la promesse mobile spécifique de `Doctrine Cobalt`:

- voir vite
- comprendre vite
- agir vite

Éléments visés:

- KPI ou bloc santé compact
- cartes d’alerte/action
- lecture IA courte
- prochaine meilleure action
- bottom navigation produit

### Mobile detail/action

Objectif: montrer comment un détail métier reste exploitable sur mobile sans perdre en confiance ni en lisibilité.

Éléments visés:

- résumé d’entité
- facts cards
- activité récente
- synthèse / risque IA
- actions collées en bas

## Lecture produit

Avec ce round, `Doctrine Cobalt` ne couvre plus seulement des pages, mais aussi deux briques critiques du système:

1. le pattern latéral de consultation/action
2. la traduction mobile centrée sur l’arbitrage rapide
