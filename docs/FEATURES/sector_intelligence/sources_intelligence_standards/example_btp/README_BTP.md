# Exemple BTP — cas de référence

Le fichier `kredo_btp_sources_reference.html` est le cas ayant servi de point de départ à la standardisation.

Il illustre notamment :

- la distinction T1/T2/T3/T4 ;
- le rôle central des marchés publics dans un secteur exposé à la commande publique ;
- l'identification d'une fédération métier et de sa presse spécialisée ;
- l'usage des grands donneurs d'ordre comme sources de trigger events ;
- l'usage des offres d'emploi et références technologiques comme indices de feuille de route SI ;
- la séparation entre pack minimal et sources complémentaires.

Ce cas est **un exemple d'instanciation**, pas un template à copier littéralement : les familles de sources restent stables, les institutions et médias changent selon le secteur.
