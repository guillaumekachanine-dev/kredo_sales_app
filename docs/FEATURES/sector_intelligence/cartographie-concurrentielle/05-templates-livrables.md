## 4. Battle card (1 page, le format que les commerciaux liront vraiment)

À extraire du livrable pour les seuls comptes prioritaires. Contrainte absolue : **une page, lisible en 90 secondes avant un appel**.

```markdown
# [NOM] — battle card · maj [DATE]

**En une phrase** : [qui c'est, position sur le marché, ce qui le caractérise]

**Ce qu'il faut savoir avant d'appeler**
- Position : [catégorie], [X] M€, [N] collaborateurs, [rayon]
- Ce qui les occupe en ce moment : [1-2 chantiers, sourcés]
- Ce qui a changé récemment : [trigger daté]

**Chez qui entrer** — [fonction] · voie d'entrée : [panel / accord-cadre / direct]

**Accroche** (à dire tel quel)
> « … »

**Nos 3 preuves à sortir** : 1) — 2) — 3)

**Objections attendues → réponse**
| « … » | → |
| « … » | → |

**Lignes rouges** : [sujets à ne pas aborder]

**Face à leurs concurrents, ils se distinguent par** : [—]
**Leur point faible exploitable** : [—]
```

## 6. Spécification de la matrice visuelle

**Carte principale — positionnement**

| Élément | Codage | Justification |
|---|---|---|
| Axe X | Empreinte métier (1-5) : part de la chaîne de valeur couverte | Répond à « jusqu'où va ce compte dans son métier », donc à l'étendue du besoin SI |
| Axe Y | Maturité numérique et d'innovation (1-5) | Répond à « ce compte achète-t-il de la transformation ou du maintien » |
| Taille de bulle | CA du périmètre pertinent | Rend visible le poids économique sans en faire un axe |
| Couleur | Catégorie (leader / challenger / mid-market / émergent / niche) | Permet de lire la structure du marché d'un coup d'œil |
| Contour épais | Compte étalon | Repère de lecture |

**Ce que la carte doit faire apparaître immédiatement** :
- le **quadrant haut-droite** (empreinte large + maturité forte) : comptes exigeants, cycles longs, gros potentiel — cible des équipes seniors ;
- le **quadrant bas-droite** (empreinte large + maturité faible) : **la zone la plus rentable pour une ESN** — un besoin étendu, une maturité insuffisante pour le traiter en interne ;
- le **quadrant haut-gauche** : spécialistes technologiques, souvent déjà bien outillés, à aborder par l'expertise pointue ;
- le **quadrant bas-gauche** : faible priorité, sauf trigger particulier.

**Carte secondaire (optionnelle) — priorisation** : X = indice d'appétence (/35), Y = accessibilité (note du critère accessibilité), taille = CA. Cette carte-là est celle qui sert en revue de pipeline.

**Version texte obligatoire** (pour la lecture sans outil) — grille 5×5 :

```text
Maturité
numérique
   5 |            [C]           [A]*
   4 |      [E]         [B]
   3 |                  [D]     [F]
   2 |            [G]                 [H]
   1 |   [I]
     +----------------------------------
       1     2     3     4     5   Empreinte métier
   * = compte étalon
```

## 7. Schéma d'export (CSV)

Pour l'import CRM, à plat. Le JSON complet (schéma dans `01-prompt-generique.md`) reste la source de vérité ; le CSV en est la projection.

```csv
nom;identifiant_national;groupe;branche_retenue;categorie;ca_meur;exercice;perimetre_ca;effectif_france;rayon;code_activite;convention_collective;empreinte_metier;maturite_numerique;reputation;appetence_total;angle_entree;confiance;date_snapshot
```

**Correspondance recommandée vers un CRM** :

| Champ export | Usage CRM |
|---|---|
| `categorie` | Segmentation de compte → détermine le discours et le niveau d'interlocuteur |
| `appetence_total` | Score de priorisation → tri de la liste de prospection |
| `trigger_events` | Tâches datées avec échéance de rappel |
| `angle_entree` | Champ de note visible sur la fiche compte |
| `confiance` | Champ qualité — un commercial doit savoir qu'il travaille sur une fiche faible |
| `date_snapshot` | Déclenche l'alerte de péremption |

## 8. Page de garde et estampillage

À apposer sur tout livrable diffusé. Sans estampillage, une cartographie continue de circuler deux ans après sa péremption — c'est le mode d'échec le plus banal et le plus coûteux.

```markdown
---
Secteur : [—] · Segment : [—] · Géographie : [—]
Compte étalon : [—]
Snapshot : [JJ/MM/AAAA] · Version : [X.Y] · Auteur : [—]
Confiance globale : [ÉLEVÉE / MOYENNE / FAIBLE]
À rafraîchir avant le : [JJ/MM/AAAA]  (triggers : 3 mois · financier : 12 mois)
Diffusion : interne — contient des appréciations nommées sur des entreprises tierces
---
```
